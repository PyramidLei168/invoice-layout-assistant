# 🧾 发票拼版助手 · Invoice Layout Assistant

> 出差报销好帮手：把各种发票 PDF 拖进来，自动转成图片、统一缩放到 A4 页面，
> 金额自动识别、每页自动汇总，一键导出 Word 直接打印。

**完全免费 · 开源 · 纯本地处理 · 发票数据不上传任何服务器**

---

## ✨ 功能特性

| 功能 | 说明 |
|------|------|
| 📄 批量拖入 | 支持 PDF / 图片 / zip，也支持**整个文件夹**直接拖入 |
| 🔄 自动转图 | PDF 每一页自动渲染成高清图片（150/200/300 DPI 可选） |
| 📐 统一缩放 | 所有发票按同一宽度缩放，自动居中排版、自动分页 |
| 💰 金额识别 | 自动读取发票金额并填入，识别不准可随时手动改 |
| 📊 每页汇总 | 页面底部自动显示「本页 N 张 · 合计 ¥X.XX」 |
| 📄 导出 Word | 生成的 .docx 与屏幕排版 1:1 对应，可继续编辑 |
| 🖼️ 导出图片 | 每页 A4 一张 300 DPI 高清 PNG（打包 zip） |
| 🖨️ 直接打印 | 浏览器打印，选「实际大小/无边距」即可 |
| 🔒 隐私优先 | **所有处理在浏览器内完成，发票永不上传** |

## 💰 金额自动识别支持范围

| 发票类型 | 识别规则 | 状态 |
|---------|---------|------|
| 电子发票（增值税/普通） | 价税合计（小写） | ✅ |
| 电子发票（小写缺失） | 价税合计（大写）中文数字 | ✅ |
| 电子发票（合计行） | 金额 + 税额 相加 | ✅ |
| 滴滴/出租车行程单 | 总计可开票金额 | ✅ |
| 机票 / 火车票 | 票价 | ✅ |
| **铁路电子客票（GBK-EUC-H 编码）** | 票价 | ✅ |

> ✅ **铁路电子客票已完全支持**
> 这类 PDF 使用 `GBK-EUC-H` 编码且未内嵌字体。关键是给 pdf.js 正确传入
> CMap 映射表（`cMapUrl`），并把字体交给系统回退处理——票面汉字与金额
> 都能正常显示和识别，无需任何额外字体文件。

## 🚀 快速开始

### 在线使用
直接打开网页即可，无需安装、无需注册。

### 本地运行
```bash
# 任选其一
python3 -m http.server 8000
npx serve .
```
然后访问 `http://localhost:8000`

> 必须通过 HTTP 服务访问，不能直接双击 index.html（浏览器安全策略限制 ES Module）。

### 部署到 GitHub Pages
1. Fork 本仓库
2. 仓库设置 → Pages → Source 选择 `main` 分支根目录
3. 等待 1~2 分钟，访问 `https://<你的用户名>.github.io/<仓库名>/`

## 🖱️ 使用技巧

| 操作 | 方法 |
|------|------|
| 调整左右宽度 | 拖动中间竖条 |
| 选中发票 | 单击 |
| 移动位置 | 拖动（可跨页拖） |
| 缩放单张 | 拖动右下角蓝色手柄 |
| 旋转 90° | 选中后按 `R` 或点「旋转」 |
| 微调位置 | 方向键（`Shift` + 方向键 大步长） |
| 移出排版 | 按 `Delete` |
| 打印设置 | 选「实际大小/100%」、边距「无」、关闭页眉页脚 |

## ❓ 常见问题

**Q: 金额没识别出来怎么办？**
A: 在左侧金额框手动填写即可，汇总会实时更新。

**Q: 支持哪些浏览器？**
A: Chrome / Edge / Firefox / Safari 近两年版本。

**Q: 发票数据安全吗？**
A: 完全安全。PDF 解析、图片转换、金额识别、文档生成全部在您的浏览器内完成，
没有任何数据上传。断网也能正常使用。

**Q: 导出图片里的汇总文字显示成方块？**
A: 系统缺少中文字体时可能出现。Windows/macOS 自带中文字体，一般无此问题。

**Q: 为什么曾经要加载一个 5MB 的 PDF 引擎？**
A: 早期为了兼容铁路电子客票引入了 pdfium WASM，但实测它在浏览器里既慢
（首次加载约 60 秒）又无法渲染任何文字（缺少字体系统接口）。现已移除：
真正的原因是 CMap 没传对，pdf.js 本身完全能处理这类 PDF。
